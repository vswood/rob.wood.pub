Matrix and Vector Manipulation Language

MVML Context Free Grammar (Backus-Naur form)

<program> --> mvml <decllist> <stmtlist> /mvml
<decllist> --> <decl>; <decllist>
<decllist> --> Epsilon
<decl> --> matrix Id = matrix(number ; number);
<decl> --> vector Id = vector(number);
<decl> --> scalar Id = number;
<stmtlist> --> <stmt>;<stmtlist>
<stmtlist> --> Epsilon
<stmt> --> Id = <expr>
<stmt> --> fill(Id);
<stmt> --> out(String);
<stmt> --> print(Id);
<expr> --> <term> <moreexpr>
<moreexpr> --> + <term> <moreexpr>
<moreexpr> --> - <term> <moreexpr>
<moreexpr> --> Epsilon
<term> --> <factor> <moreterm>
<moreterm> --> * <factor> <moreterm>
<moreterm> --> Epsilon
<factor> --> Number
<factor> --> Id
<factor> --> ( <expr> )
