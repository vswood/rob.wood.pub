Matrix and Vector Manipulation Language

MVML IDE

The MVML Integrated Development Environment is a VB.Net application which runs in Windows and allows users to open, create, and save mvml files, compile the source code into XML and assembly code, and assemble the asm code into an executable file (assembly is done in a DOS environment via a batch file).

Download the MVML IDE

The help file for the MVML IDE explain how to write, compile, assemble, and run MVML programs.
