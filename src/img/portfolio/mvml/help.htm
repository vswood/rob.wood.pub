Matrix and Vector Manipulation Language

MVML IDE Help

The MVML Integrated Development Environment is a VB.Net application which runs in Windows and allows users to open, create, and save mvml files, compile the source code into XML and assembly code, and assemble the asm code into an executable file (assembly is done in a DOS environment via a batch file).

Working in the IDE

Use the Source menu to open an mvml file or to create a new one. The Save option saves your mvml, but any code in the editor is saved automatically when compiled as well. If you need help with matrix and vector math, use that option from the Help menu.

Variable Declaration

MVML allows the creation of matrix, vector, and scalar objects with integer values between -9999 and 9999 with the following format:
variableType identifier = variableType (dimension/s)
Note that scalar values should not be used with the fill command and should be assigned values within their declaration.

Examples:

A 2x2 matrix named "A":

matrix A= matrix(2;2);

A vector named "B" with a length of 2:

vector B= vector(2);

A scalar value named "sclr" equal to 2:

scalar sclr=2;

Matrix and Vector Mathematical Operations

Once you have defined some variables, you can perform some elementary mathematical manipulations. Only one operation can be used in an expression, and naturally your dimensions must be correct for the operation you are performing. Also, with scalar multiplication, the scalar value must be the second operand of the operation.

Examples:

Assuming matrix named "A" and "B", vectors named "c" and "d", and a scalar "e", with appropriate dimensions being assigned to an appropriately sized variable:

x=A*B;
x=A*c;
x=A*e;
x=c*d;
x=c*e;
x=A+B;
x=c+d;
x=A-B;
x=c-d;

Variable Input and Output

To display a matrix, vector, or scalar variable, simply use the print statement, passing in the appropriate variable name:

Examples:

print(x);

To display a label, use the out statement, passing in a line of output enclosed in quotes:

Examples:

out("This statement will be printed on the screen");

The fill command will prompt the user for input with which to fill a matrix or vector:

Examples:

fill(x);

Building Executable Programs

Once you have written your code, place it in the project folder inside the MVML IDE folder, then you can compile it, using ctrl+shift+c or the Compile option on the Build menu. Once your code has been compiled, you can use the Output menu to view the compiler's output. Any code errors will be shown in the generated XML code. Arithmetic dimension errors will be reported in the executable at runtime. If your code has no errors and everything looks ok, you can save your assembly code (ctrl+shift+s or via the Output menu) and then assemble the .asm file into an executable program by pressing alt+1 or clicking the Assemble option from the Build menu. This will start a batch file in a DOS window. Enter the name of the mvml program file with no extensions. If there are no assembly errors, you will then be able to enter "project\" plus the program file name, again with no extensions, and your program will run. You can run your program any other time by simply clicking its .exe file.
